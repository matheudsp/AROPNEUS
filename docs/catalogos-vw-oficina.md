# Catálogos VW da oficina — base para consulta

**As opções de coding variam conforme o ano, a versão e os equipamentos do veículo. Fale com a Aro Pneus para confirmar os serviços disponíveis para o seu carro.**

Este é um catálogo parcial. A seleção representa interesses para orçamento, não um diagnóstico nem confirmação de execução por VCDS. A ausência de um modelo ou função não significa incompatibilidade.

Ferramentas informadas: HEX-V2 e VCDS 26.9.

Os rótulos de versão e os intervalos de ano são os declarados nos materiais e não foram validados por VIN. Os catálogos não são mapas técnicos de execução. As exigências de hardware listadas como “verificar” são orientações para triagem, distintas das restrições explícitas de cada PDF.

## Regras para o seletor

- Solicitar ano e versão do cliente mesmo quando o catálogo não informar uma faixa.
- Não atribuir todos os anos a um catálogo sem ano declarado.
- Exibir “opções citadas no catálogo — confirme para seu carro”.
- Preservar diferenças entre ativar/desativar, farol alto contínuo/lampejo, botão de partida/sistema start-stop e trancamento por velocidade/ao sair.
- Manter funções de alertas, condução e sinalização identificadas para avaliação técnica; sua presença no material não é aprovação de execução.
- Não exibir os PDFs originais, a senha, a marca d’água ou dados de licenciamento no site.
- Não inventar preços por função.
- Para modelos sem catálogo, oferecer o mesmo contato de consulta.
