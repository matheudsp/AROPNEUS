## Fluxo sugerido para o site

1. Selecionar marca, modelo, ano-modelo e versão; identificar geração e mercado quando necessário.
2. Informar equipamentos relevantes: painel, central, retrovisores, faróis, alarme.
3. Exibir apenas funções mapeadas para aquela geração; sem mapeamento, oferecer consulta técnica, sem gerar disponibilidade fictícia.
4. Cliente seleciona interesses, ainda sujeitos à validação técnica.
5. Enviar ao WhatsApp 5589994136771 o carro, equipamentos e funções desejadas.
6. Após leitura dos módulos e validação da ferramenta, registrar por exemplar: confirmado / exige equipamento / não suportado / pendente.
